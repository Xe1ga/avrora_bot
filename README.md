# avrora_bot

Чат-бот VK для автоматизации управления волейбольным клубом «Аврора» (г. Вологда).

Реализован **Этап 1 (MVP)** согласно «Техническое задание на разработку.md»:
регистрация и ролевая модель, учёт абонементов (голосование → расчёт →
фиксация оплат → отчёт), разовые посещения с редактируемым тарифом, календарь
тренировок/игр, журнал административных действий.

## Технологии

Python 3.14 · vkbottle (Long Poll) · SQLAlchemy 2.0 (async) + Alembic ·
PostgreSQL 16 · openpyxl · structlog · Docker Compose. Управление зависимостями — `uv`.

## Архитектура

Гексагональная (ports & adapters):

```
src/avrora_bot/
  domain/        — сущности, доменные сервисы (расчёт стоимости месяца
                   и суммы абонемента), порты (Protocol-интерфейсы)
  application/   — use case'ы и сервисы (permissions, action_log)
  adapters/
    database/    — ORM-модели, репозитории, Unit of Work, Alembic, сидинг
    vk/          — бот vkbottle, хендлеры, FSM, клавиатуры, middleware
    reports/     — генерация XLSX
  composition.py — сборка зависимостей (composition root)
  app.py         — инициализация и запуск
```

## Быстрый старт (Docker)

1. Скопируйте шаблон окружения и заполните значения:

   ```sh
   cp .env.example .env
   # отредактируйте .env: VK_TOKEN, VK_GROUP_ID, POSTGRES_PASSWORD,
   # BOOTSTRAP_ADMIN_VK_ID (ваш личный vk_id — станет администратором)
   ```

2. Запустите:

   ```sh
   docker compose up -d --build
   ```

   Контейнер дождётся PostgreSQL, применит миграции Alembic и запустит бота.

3. Напишите сообществу в VK «начать» — бот ответит меню.

## Как получить VK-токен

Сообщество → **Управление → Настройки → Работа с API**:
- **Ключи доступа** → создать ключ с правами «Сообщения сообщества» и
  «Управление сообществом» → это `VK_TOKEN`.
- **Long Poll API** → включить, версия API 5.199, событие «Входящее сообщение».
- **Сообщения** → включить сообщения сообщества.

## Команды бота (Этап 1)

Игрок: `начать`, `помощь`, `регистрация`, `мой статус`, `календарь [YYYY-MM]`.

Сборщик платежей:
- `расчёт YYYY-MM <кол-во>` — предварительный расчёт суммы абонемента;
- `голоса YYYY-MM` + список vk_id (с новых строк) — зафиксировать голосование;
- `сумма YYYY-MM <значение>` — переопределить сумму на человека;
- `оплатил YYYY-MM <vk_id>` / `не оплатил YYYY-MM <vk_id>`;
- `сводка YYYY-MM` — краткий отчёт; `xlsx YYYY-MM` — полный отчёт файлом;
- `разовый тариф <сумма>`, `разовое <vk_id> [ДД.ММ.ГГГГ]`, `разовые YYYY-MM`.

Куратор: `событие ДД.ММ.ГГГГ <тренировка|игра> <ЧЧ:ММ|-> <место>`,
`удалить событие <id>`.

Администратор: `заявки`, кнопки подтверждения/отклонения,
`добавить <vk_id> <роль> <ФИО>`, `роль <vk_id> <роль>`, `снять роль <vk_id> <роль>`.

## Границы MVP

Фиксация оплат — вручную сборщиком (перевод на карту вне бота). Публикация
постов, уведомления о ДР, чтение опросов VK, сборы на подарки, интеграция с
платёжными API — следующие этапы (см. ТЗ, раздел 6).
